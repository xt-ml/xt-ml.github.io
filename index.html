Static Publishing with ShadowClaw

Sites across the organization leverage ShadowClaw's dual-root build pipeline and CLI tool for local development and CI/CD:

Local Development

# Start local development server on http://127.0.0.1:8888
npx shadow-claw dev

# Or compile static production distribution into ./dist/public
npx shadow-claw build --prod

Deployment Strategies

  • Strategy A (Full Fork): Clone or fork xt-ml/shadow-claw with custom in-repo pages.
  • Strategy B (Pages-only Repo): Content repo that checks out xt-ml/shadow-claw in GitHub Actions CI.
  • Strategy C (NPM / CLI): Fast build directly via npx shadow-claw build --prod in GitHub Actions.
